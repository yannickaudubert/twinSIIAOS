# Pre-machine cognitive contract

This contract keeps cognitive modes, host truth and execution governance above any single model/runtime provider.

## Core separations

- model != runtime != agent != tool != capability != host;
- declared/historical state != fresh ObservedState;
- consensus != evidence;
- simulation != reality;
- checkpoint != compensation;
- projection != canonical state;
- AI-derived knowledge != admitted knowledge.

## Strategy contract

Cognitive modes are addressed as strategy identifiers and versioned contracts. Character/persona names may exist only as optional human-facing aliases and never as canonical runtime identifiers.

## Golden Mission

The pre-machine gates in golden-mission-gates.json are intentionally split between gates that can be proved before SandY access and gates that require fresh runtime observation.

The contract does not claim any local runtime is active, safe, benchmarked or admitted.
