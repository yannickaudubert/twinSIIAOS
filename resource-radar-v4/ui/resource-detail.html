Arbitrage

Retenir, écarter, comparer.

À retenir si

  • une base vectorielle dédiée est justifiée ;
  • les filtres et la recherche hybride comptent ;
  • l’exploitation d’un service séparé est acceptable.

À écarter si

  • un store embarqué suffit ;
  • l’équipe veut minimiser le nombre de composants ;
  • le besoin principal est relationnel ou analytique.

À comparer avec

  • Weaviate pour une approche plus plateforme ;
  • Chroma pour certains usages plus intégrés ;
  • Postgres/pgvector si la consolidation prime.
