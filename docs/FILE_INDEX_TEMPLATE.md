## Règles

- une ligne par fichier suivi utile à la reprise ;
- les assets peuvent être regroupés par famille seulement si leur rôle et provenance sont homogènes ;
- les fichiers générés doivent pointer vers leur générateur ;
- les migrations ne sont jamais regroupées si leur impact diffère ;
- les fichiers de sécurité, auth, policy, persistence et migration sont toujours décrits individuellement ;
- `UNKNOWN` est préférable à une explication inventée ;
- toute suppression ou renommage met à jour cet index ;
- pour les gros dépôts, ce tableau peut être généré depuis un manifeste machine-readable, mais le résultat doit rester lisible par un humain.
