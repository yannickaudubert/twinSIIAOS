# P0 Skill Gap Analysis

This analysis compares the first upstream candidate wave with the observed SIIAOS custom skills.

It deliberately separates four questions:

1. **Does an upstream capability exist?**
2. **Do we already cover it locally?**
3. **Should we adapt or keep it as an upstream candidate?**
4. **Has it passed admission?**

Only the fourth question is controlled by the Capability Core lifecycle.

## Current direction

### Adapt locally first

- verification-before-completion
- systematic-debugging

These address recurring failure patterns and must use SIIAOS truth/evidence semantics.

### Specialist candidates

- Trail of Bits audit-context-building
- differential-review
- agentic-actions-auditor
- Superpowers TDD

These provide specialist capabilities rather than replacing existing project-context skills.

### Adapt, do not copy

- executing-plans
- to-spec
- to-tickets

Their useful mechanics overlap our control-plane skills or contain environment-specific publication assumptions. Extract the reusable method while preserving SIIAOS authority, HumanGate and adapter boundaries.

### n8n

Treat all 14 official n8n skills as separate candidates. They cover distinct operational capabilities and should be admitted independently.

## Non-goal

This folder does not install or promote anything. A proposed disposition cannot change a canonical skill record from `CANDIDATE` to `SCANNED`, `REVIEWED`, or `ADMITTED`.
